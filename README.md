# 시장날씨 v0.1 — 비전공자를 위한 매크로 트레이딩 앱

오늘의 시장날씨, 내 자산, 종목 진단, 코인, 매매일지를 한 앱에서 봅니다.
휴대폰 홈 화면에 설치할 수 있는 **웹앱(PWA)** 이고, 따로 설치할 프로그램이 없습니다.

## 1. 바로 열어 보기 (컴퓨터)

- `index.html`을 더블클릭하면 브라우저(크롬 권장)에서 열립니다.
- 더 정확하게 보려면 이 폴더에서 아래 중 하나를 실행한 뒤 `http://localhost:8000`을 엽니다.
  - `python3 -m http.server 8000`
  - `npx serve -l 8000`
- Claude Code에서는 "이 폴더를 로컬 서버로 띄워줘"라고 하면 됩니다.

## 2. 휴대폰에 설치하기

웹 주소가 있어야 휴대폰에 설치됩니다. 무료로 올리는 방법은 두 가지입니다.
- **Netlify Drop**: netlify.com/drop 에 이 폴더를 끌어다 놓으면 주소가 바로 생깁니다.
- **GitHub Pages**: 저장소에 올리고 Settings → Pages 를 켭니다.

휴대폰에서 그 주소를 연 뒤 공유 버튼 → "홈 화면에 추가"를 누르면 앱처럼 설치됩니다.

## 3. 무엇이 실시간이고 무엇이 고정값인가

| 항목 | 출처 | 갱신 |
|---|---|---|
| 코인 원화 시세, 24시간 변화 | 업비트 (막히면 CoinGecko) | 1분마다 |
| 코인 일봉 (추세 점수용) | 업비트 (막히면 CoinGecko) | 1시간 |
| 코인 공포·탐욕 지수 | alternative.me | 1시간 |
| 코인 전체 시가총액, 도미넌스 | CoinGecko | 10분 |
| 원/달러 환율 | Frankfurter (유럽중앙은행 기준환율) | 하루 1번 |
| 미국 금리·달러지수·유가·VIX·주가지수, 중앙은행, 일정, 업종 | `js/snapshot.js` | **직접 수정** |

인터넷이 끊기면 마지막으로 받은 값을 보여 줍니다.

> 제가 만든 환경에서는 인터넷 접속이 막혀 있어서, 위 API들을 실제로 불러오는 것까지는 시험하지 못했습니다. 화면이 모두 그려지는지와 점수 규칙 계산은 시험을 통과했습니다. 처음 열었을 때 코인 시세가 "불러오는 중"에서 멈추면, Claude Code에 "브라우저 개발자 도구 콘솔 오류를 확인해서 고쳐줘"라고 하세요.

## 4. 숫자를 새로 넣는 법

`js/snapshot.js`를 열어 숫자와 `asOf`(기준일)를 바꾸고 저장하면 끝입니다.
매일 아침 루틴: 미국 10년물, 달러지수, 브렌트유, S&P 500, VIX, "어제 왜 움직였나" 3줄.

## 5. 점수·날씨 규칙

모든 판단은 `js/rules.js` 한 파일에 공개된 규칙대로만 계산합니다. 숫자만 고치면 규칙이 바뀝니다.

- **시장날씨**: 역풍 5가지(금리 4.5% 이상, 달러지수 102 이상, 브렌트 90달러 이상, VIX 25 이상, 공포탐욕 25 이하) 중 몇 개가 켜졌는지로 맑음 → 폭풍우.
- **종목 진단 (5개 항목 × 20점)**
  - 매크로 바람: 20점에서 금리·달러·연준 인상 예상만큼 감점
  - 가격 추세(코인): 20일·60일 이동평균과 비교
  - 심리(코인): 공포가 클수록 역발상 가점
  - 수요(코인): 미국 현물 ETF 자금 흐름
  - 업종 사이클(주식): 로테이션 4칸 위치
  - 이벤트 위험: 다음 큰 일정까지 남은 날
  - 주식의 실적·주가 추세는 데이터 연결 후(다음 버전) 계산하고, 지금은 부분 점수로 표시
- **사이클 '지금 여기'**: 연준 금리 방향 + 시장날씨 역풍 개수로 자동 판단

점수는 사라·팔라는 신호가 아니라 "지금 조건이 얼마나 유리한가"입니다. 앱을 공개할 때도 이 문구를 꼭 유지하세요.

## 6. 내 자산 — 빗썸·토스증권 계좌 연결

`connect` 폴더의 **동기화 프로그램**이 내 컴퓨터에서 빗썸과 토스증권에 "조회"만 요청해 보유 자산을 받아옵니다. 주문·출금 기능은 코드에 아예 없습니다.

### 처음 한 번만 준비 (약 20분)
1. **Node.js 설치**: nodejs.org 에서 LTS 버전을 받아 설치합니다(설치돼 있으면 건너뜀).
2. **내 컴퓨터 공인 IP 확인**: 네이버에 "내 IP 주소"를 검색합니다. 두 곳 모두 이 IP를 등록해야 합니다.
3. **빗썸 API 키**: 빗썸 웹 → 마이페이지 → API 관리 → API 2.0 키 발급
   - 권한은 **자산 조회만** 체크하세요. 주문·출금은 절대 체크하지 마세요.
   - 허용 IP에 2번의 IP를 넣습니다.
4. **토스증권 API 키**: 토스증권 PC 웹(WTS) → 설정 → Open API
   - Client ID와 Client Secret이 나옵니다(유효기간 1년).
   - 허용 IP 관리에 2번의 IP를 넣습니다. 안 넣으면 `ip-not-allowed` 오류가 납니다.
   - 토스증권 키는 조회 전용 권한이 따로 없어 **주문까지 가능한 키**입니다. 이 프로그램은 조회만 하지만, 키가 새면 위험하니 절대 남에게 보내지 마세요.
5. `connect/.env.example` 파일을 복사해 이름을 `.env`로 바꾸고 키 4개를 채웁니다.

### 동기화할 때마다
- 윈도우: `connect/동기화-윈도우.bat` 더블클릭
- 맥: `connect/동기화-맥.command` 더블클릭
- 끝나면 앱을 새로고침하면 "내 자산"에 반영됩니다. 토스증권 종목은 목록에서 업종을 한 번 골라 주면 진단점수가 더 정확해집니다.

### 꼭 지킬 것
- `.env`(키)와 `js/holdings-live.js`(내 보유 자산)는 **인터넷에 올리면 안 됩니다.** Netlify나 GitHub에 앱을 올릴 때는 이 두 파일을 빼세요(.gitignore 에 이미 넣어 두었습니다).
- 휴대폰에서도 실제 내 자산을 보려면 로그인이 있는 작은 서버가 필요합니다(다음 단계).

직접 입력한 자산은 이 브라우저 안(localStorage)에만 저장되고, 어디로도 보내지 않습니다.

## 7. 진단 점수 계산법 (v0.4)
점수는 `js/rules.js`의 조건표로만 계산합니다. 조건마다 점수를 주고, 묶음별 0~100점을 낸 뒤 가중치로 평균합니다. 데이터가 없는 묶음은 빼고 남은 가중치로 나눕니다.

- **코인 (33개 조건)**: 매크로 환경 15% (금리 수준, 연준 방향, 장단기 금리차, 달러, 유가, VIX) · 가격 추세 25% (20/60/120/200일 평균, 정배열, 평균 기울기, 30·90일 수익률, 고점 대비) · 탄력·과열 15% (RSI, 이격도, 볼린저밴드, 연속 등락) · 변동성·위험 10% (변동성, 최대 낙폭, ATR) · 거래·유동성 10% (거래대금 변화, 매수·매도 우위, 유동성) · 수급·심리 20% (공포탐욕, ETF 자금, 도미넌스, 비트코인 대비 힘, 대장 추세) · 일정 위험 5%
- **주식**: 매크로 25% · 업종 환경 35% (사이클 위치, 1달·올해 성과, 금리·유가·불안장과의 궁합, 환율 또는 수출 수혜, 한국은행 방향) · 일정 10% · 주가 추세 20%와 실적 10%는 데이터 연결 후 반영
- **스테이블코인**은 점수 대상이 아닙니다.
- **내 포지션 점검**: 보유 종목에서 진단하면 손익률·비중에 따른 점검 문구가 추가됩니다(점수와 별개).
- 업종 자동 분류표는 `js/tickers.js`에 있습니다.

## 8. 행동 가이드 · 화면 · 발표 모드 (v0.5)
- **행동 가이드** (`js/rules.js`의 `actionFor`): 진단점수 + 추세(60일 평균·정배열) + 과열(RSI·이격도) + 내 손익 + 비중을 합쳐 한 가지를 고릅니다.
  - 손절 기준 점검: 손실 -15% 이하 + 점수 40 미만 + 하락 추세
  - 비중 축소 검토: 한 종목이 자산의 40% 이상
  - 분할 매도 검토: 수익 +20% 이상이면서 과열, 또는 수익 +50% 이상, 또는 점수 35 미만인데 아직 수익
  - 분할 매수 검토: 점수 55 이상 + 과열 아님 + 비중 25% 미만 + 상승 추세 속 눌림
  - 소량 분할 매수: 과매도(RSI 30 미만) + 시장 공포 + 비중 20% 미만
  - 그 밖에는 보유 유지(미보유는 관망), 스테이블코인은 현금성 자산
  - 분할 계획 가격은 ATR(하루 평균 흔들림)과 20·60일 평균, 볼린저밴드로 계산합니다.
- **화면**: 기본은 눈이 편한 밝은 화면. 오른쪽 위 달 모양 버튼으로 어두운 화면으로 바꿀 수 있습니다.
- **발표 모드**: 오른쪽 위 모니터 모양 버튼. 실제 보유 내역 대신 예시 데이터로 보여 줍니다(다시 누르면 원래대로).
- 행동 가이드는 규칙 기반 참고 정보이며 투자 권유가 아닙니다.

## 9. 오늘의 자산 순위 · 업종 자동 인식 (v0.6)
- **오늘의 자산 순위** (홈 → TOP 10): 나스닥·S&P500·코스피·코스닥·금·원유·달러 7개 + 주요 코인 10개(BTC·ETH·XRP·SOL·DOGE·ADA·LINK·AVAX·SUI·TRX)를 같은 0~100점으로 줄 세웁니다. 순위를 누르면 유리한 이유 2개와 주의할 점 1개가 나옵니다.
  - 코인: 실시간 200일 가격으로 33개 조건 (앱을 열 때마다 새로 계산)
  - 지수·금·원유·달러: 거시 환경과 자산 성격의 궁합(금리·달러·불안·유가·환율·한국은행) + 1년·하루 수익률. 숫자는 `js/snapshot.js`의 `markets`와 `rankAssets`에 있으며, 새로 넣을 때 `asOf`도 함께 바꿉니다.
  - 금·달러 같은 안전자산에는 "금리·달러가 높으면 역풍" 같은 위험자산용 조건을 쓰지 않습니다.
- **업종 자동 인식**: 진단 화면에서 "삼성전자", "엔비디아", "NVDA", "005930"처럼 쓰면 업종이 자동으로 골라집니다(약 160개 이름). 사전은 `js/tickers.js`의 `NAMES`에 있습니다.

## 11. 세계 돈의 지도 (v0.8)
- 홈 아래 "세계 돈의 지도". 부동산·채권·주식·금·은·암호화폐·비트코인의 시장 크기, 중국·미국·유로존·일본·한국의 돈의 양(M2), 통화별 외환거래·외환보유액 비중을 한 화면에 비교합니다.

## 12. 가격 차트 (v0.9)

- 데이터: 코인은 업비트 200일, 주식·지수·금·은·유가·금리·환율은 `node market.mjs`로 받은 1년치(원/엔·원/위안·원/유로는 달러 환율로 교차 계산).

## 13. 10년치 기록 (v1.0)

  - 10년 전체 → `js/history/종목.js` 파일 하나씩 (차트에서 3년·5년·10년을 누를 때만 읽어서 앱이 느려지지 않음)
- 차트 기간: 1달·3달·6달·1년(일봉) · 3년·5년(주봉) · 10년(월봉). 이동평균도 20·60주선, 20·60개월선으로 바뀝니다.

## 14. 전문가용 분석 도구 (v1.1)
차트 위 버튼으로 켜고 끕니다(설정은 기기에 저장). 계산은 `js/ta.js`, 테스트는 `tests/ta.test.js`.
- **추세선**: 차트의 전환점(스윙 고점·저점) 가운데 최근 두 저점을 이은 지지 추세선(빨강), 두 고점을 이은 저항 추세선(파랑)을 오른쪽으로 연장
- **지지·저항**: 전환점 가격이 1.5% 안에 여러 번 모인 가격대를 현재가 아래 2개(지지)·위 2개(저항)
- **볼린저밴드**(20일, ±2σ) · **선형회귀 채널**(로그 가격 추세선 ±2σ, 미래까지 연장) · **피보나치 되돌림**(23.6·38.2·50·61.8·78.6%)
- **예상 범위**: 최근 60봉 변동성으로 계산한 68%·95% 확률 범위를 오른쪽 "앞으로" 칸에 원뿔로 표시. 방향 예측이 아니라 통계적 흔들림의 폭
- **아래 칸**: 거래대금 / RSI(14, 30·70선) / MACD(12·26·9, 히스토그램) / 스토캐스틱(14·3·3, 20·80선)
- **기술적 분석 리포트**: 회귀 추세(연율·R²), 채널 안 위치(σ), 볼린저 %B·스퀴즈, MACD 교차, RSI, 스토캐스틱, 가까운 지지·저항, 피보나치 위치, 1달·3달 뒤 68%·95% 예상 범위, 종합 신호

## 15. 자산 진단 · 투자성향별 비중 (v1.2)
- 내 자산 → "자산 진단". 질문 5개(투자 기간·손실 반응·경험·비상금·목표)로 투자성향 5단계(안정형~공격투자형)를 정합니다.
- 성향별 권장 비중(현금·주식·코인): 안정형 70·30·0 / 안정추구형 50·45·5 / 위험중립형 30·60·10 / 적극투자형 20·65·15 / 공격투자형 10·65·25. 시장날씨 역풍 4개 이상이면 현금 +5%p. 일반적인 출발점이며 개인 자문이 아닙니다.
- 100점 평가: 자산 배분 25 · 분산 20 · 위험 수준 20 · 손익 관리 15 · 보유 종목 조건 20 → 등급 A~F와 "냉정한 한마디", 목표 비중까지 옮길 금액.
- 위험 수준: 종목별 최근 60일 변동성(하한 코인 30%·주식 12%)과 종류별 상관으로 포트폴리오 연간 변동성과 "나쁜 해(20년에 한 번 꼴) 예상 손실"을 계산.
- 스테이블코인은 현금으로 봅니다. 빗썸 원화 외의 현금(은행·토스증권 예수금 등)은 진단 화면에서 직접 넣으면 함께 계산합니다.
- 규칙: `js/rules.js`의 `PROFILES`, `reviewPortfolio`.

## 16. 자산 달력 (v1.3)
- 내 자산 → "자산 달력". 월 달력 칸마다 그날 총 자산이 전날보다 얼마나(원·%) 변했는지 표시합니다. 오른 날은 빨강, 내린 날은 파랑.
- 날짜를 누르면 그날 총 자산, 코인·주식·현금 변화, 많이 움직인 종목.
- 실제 기록(점 표시): 앱을 연 날의 총 자산을 이 기기에 저장(최대 800일). 발표 모드에서는 저장하지 않습니다.
- 추정(흐린 칸): 기록이 없는 날은 지금 보유 수량 × 그날 종가(주말·휴장일은 직전 종가)로 채웁니다. 그사이 사고판 것은 반영되지 않습니다.

## 17. 포트폴리오 5축 분석 (v1.4)
- 내 자산 맨 위 요약 아래. 오각형 레이더로 내 포트폴리오를 **추세·탄력·안정성·수급·환경** 5축(각 6점)으로 보여 줍니다.
- 각 축 = 보유 종목의 해당 점수(진단 엔진의 묶음 점수)를 자산 비중대로 평균. 스테이블코인은 제외.
- 축 이름을 누르면 그 축의 점수를 "올리는 종목 / 끌어내리는 종목"을 영향(비중 × 평균과의 차이) 순으로 보여 주고, 종목을 누르면 차트로 이동.
- 가치·성장·실적·재무·배당 축은 기업 실적 데이터(국내 DART, 미국 SEC 등)를 연결하면 추가할 수 있습니다.

## 18. 월가 스크리너 · 종목 오각형 (v1.5)
- 종목 진단·차트 화면: 종목 하나를 5축 **1~100점** 오각형으로 — 가치 20% · 성장 20% · 수익성·재무 20% · 모멘텀 25% · 환경·위험 15% → 종합 점수(매우 우수·우수·보통·미흡·취약). 꼭짓점을 누르면 축별 세부 조건.
  - 가치: PER(업종 기준 대비)·PSR·PBR·EV/EBITDA·PEG·배당수익률·애널리스트 목표가까지
  - 성장: 매출 성장·이익 성장·분기 이익 성장·선행 PER로 본 예상 이익 증가
  - 수익성·재무: ROE·ROA·영업이익률·순이익률·부채비율·유동비율·잉여현금흐름·순현금
  - 모멘텀: 미너비니 트렌드 템플릿 8조건 · IBD식 상대강도 RS(전체 종목 백분위) · RSI · MACD · 3개월 시장 대비
  - 환경·위험: 베타·변동성·최대 낙폭·공매도·애널리스트 평균 의견·매크로·업종 궁합·일정
- 스크리너 체크리스트: 미너비니 트렌드 템플릿, CAN SLIM(오닐), 그레이엄 가치 기준, 버핏식 퀄리티, 애널리스트 컨센서스(평균 의견·목표가·인원).
- 재무 지표는 **공식 공시**에서 계산합니다(v1.6). 아래 19번 참고.
- 업종 기준 PER은 대략적인 장기 평균을 눈금으로 쓴 값입니다(`js/rules.js`의 `SECTOR_PE`).
- 종목 순위(나스닥·S&P500·코스피·코스닥)도 이 스크리너 종합 점수로 정렬합니다. 코인은 가격·수급·거시 기반 5축(추세·탄력·안정성·수급·환경)으로 보여 줍니다.

## 19. 공식 재무 데이터 (v1.6)
- **미국 종목 — SEC EDGAR**(미국 증권거래위원회): 무료·키 없음. 10-K·10-Q 공시의 매출·순이익·영업이익·자본·자산·부채·현금·현금흐름·주식 수로 지표 계산. `.env`의 `SEC_CONTACT`에 이메일을 넣으면 요청에 연락처로 씁니다(SEC 규칙). 해외 기업 ADR(ASML·TSM·ARM 등 IFRS 공시)은 제외.
- **한국 종목 — OpenDART**(금융감독원 전자공시): 무료·인증키 필요. https://opendart.fss.or.kr → 인증키 신청 → `.env`의 `DART_API_KEY=`에 붙여 넣기. 사업보고서 주요계정·최근 분기·주식 총수·배당수익률 사용. 고유번호 목록은 `connect/.cache`에 7일 보관.
- 계산 지표: PER·PSR·PBR·EV/EBITDA(감가상각이 공시된 경우)·PEG·배당수익률·ROE·ROA·영업이익률·순이익률·매출 성장·이익 성장·분기 이익 성장·부채비율(부채총계÷자본총계, 한국식)·유동비율·잉여현금흐름·순현금.
- 베타는 최근 1년 주가와 지수로 직접 계산합니다.
- **제외**: 애널리스트 의견·목표가, 공매도 비중, 기관 보유 — 공식 무료 출처가 없음. 야후 파이낸스 재무 요청은 모두 없앴습니다.
- 코드: `connect/fundamentals.mjs`, 테스트: `tests/fundamentals.test.mjs`.
